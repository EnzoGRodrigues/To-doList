# To-doList

Uma aplicação simples de Lista de Tarefas (To-Do List) desenvolvida em Java.

> Projeto do usuário Enzo Rodrigues (GitHub: [EnzoGRodrigues/To-doList](https://github.com/EnzoGRodrigues/To-doList))

---

## 🎯 Visão Geral

Esse projeto permite que o usuário adicione tarefas, visualize uma lista de tarefas a serem feitas e marque ou remova tarefas concluídas. É ideal para praticar conceitos de manipulação de listas, armazenamento simples, e interface mínima em Java.

---

## 🛠 Tecnologias Utilizadas

* Java (linguagem principal)
* Projeto estruturado em pasta `src` conforme o repositório mostra. ([GitHub][1])
* Arquivo `.gitignore` presente. ([GitHub][1])
* Ambiente de desenvolvimento provavelmente IntelliJ / .idea está incluso. ([GitHub][1])

---

## 📂 Estrutura do Projeto

```
/To-doList
 ├─ .idea/
 ├─ src/
 ├─ .gitignore
 └─ toDoList.iml
```

* **.idea/** – configurações de projeto da IDE.
* **src/** – código-fonte Java do sistema de tarefas.
* **.gitignore** – arquivos ignorados no versionamento.
* **toDoList.iml** – arquivo de módulo da IDE.

---

## 🚀 Como Executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/EnzoGRodrigues/To-doList.git
   ```
2. Abra o projeto em uma IDE que suporte Java (por exemplo IntelliJ, Eclipse).
3. Navegue até a pasta `src` e identifique a classe `main` (ou equivalente) que inicia o app.
4. Compile e rode a aplicação.
5. Use a interface (console ou GUI, dependendo da implementação) para:

   * Adicionar tarefas
   * Visualizar tarefas pendentes
   * Marcar tarefas como concluídas ou removê-las

> Se a aplicação exigir autenticação ou banco de dados, verifique as instruções no código (até o momento não há documentação específica no repositório).

---

## ✅ Funcionalidades Principais

* Criar uma nova tarefa.
* Listar tarefas pendentes.
* Marcar uma tarefa como concluída.
* Remover tarefas concluídas ou indesejadas.
* Armazenamento simples (lista em memória ou possível persistência, revisar código).
